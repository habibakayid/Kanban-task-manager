# Kanban Task Manager
 
A simple Kanban-style task manager built with **TypeScript** and **OOP principles**. Create, edit, move, and delete tasks across three columns — *To Do*, *In Progress*, and *Done* — with everything persisted in `localStorage`.

## Features
 
-  **Create** tasks with a title, description, priority (Low / Medium / High), and status
-  **Edit** any task through the same modal form
-  **Delete** tasks with a confirmation prompt
-  **Drag & drop** tasks between columns (or edit the status directly in the form)
-  **Persistent storage** — all tasks are saved to `localStorage`, so nothing is lost on refresh
-  Fully responsive dark-themed board
---
 
##  Tech Stack
 
- **TypeScript** (strict mode, ES2020 modules) — no JavaScript was written by hand, only compiled from `.ts`
- **HTML5 / CSS3** — no frameworks
- Native **HTML5 Drag & Drop API**
- **`localStorage`** for persistence
---
 
##  Architecture (OOP)
 
The app follows a simple layered structure, each class with a single responsibility:
 
| Class | File | Responsibility |
|---|---|---|
| `Task` | `src/models/Task.ts` | Represents a single task (data model) |
| `TaskStore` | `src/services/TaskStore.ts` | All CRUD operations + `localStorage` persistence |
| `KanbanApp` | `src/app.ts` | UI controller — renders the board, handles the modal, drag & drop, and events |
 
`TaskStore` knows nothing about the DOM, and `KanbanApp` knows nothing about `localStorage` — it only talks to `TaskStore`. This separation makes each class easy to test and reason about independently.
